# No Show Appointments Prediction

This project aims to predict whether a patient will show up for their medical appointment based on various features such as age, gender, appointment day, and more.

## Project Structure

- `data/`: Contains the cleaned dataset used in the project.
- `notebooks/`: Jupyter notebooks for exploratory data analysis and model building.
- `outputs/`: Graphs, confusion matrix images, and exported results.

## Steps Covered

1. Data Cleaning and Preparation
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Model Training (Classification Models: Logistic Regression, Random Forest, etc.)
5. Evaluation using accuracy, precision, recall, and ROC-AUC
6. Conclusion and Next Steps

## Tools & Libraries

- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- Jupyter Notebook
