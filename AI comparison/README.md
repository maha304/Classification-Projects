# AI Clinical Evaluation Comparison

This project compares the performance of two AI tools — ChatGPT and OpenEvidence — across 50 clinical cases using ordinal evaluation metrics. The goal is to assess which tool provides more accurate, relevant, and well-structured responses in a medical context.

---

## 📁 Project Structure

- `data/`  
  Contains the structured and cleaned dataset used for analysis.

- `notebooks/`  
  Includes the Jupyter notebook used for statistical and exploratory analysis.

- `reports/`  
  - `descriptive_report.docx`: Descriptive statistics and metric definitions.  
  - `test_results_report.docx`: Comparative evaluation and performance insights.

- `visualizations/`  
  Includes the visual representation of key findings (plots, graphs, summary charts).

---

## 🛠 Tools Used

- Python (Pandas, Seaborn, Matplotlib)
- Jupyter Notebook
- Microsoft Word for reporting
- Manual scoring rubric converted to numerical format

---

## 📊 Key Insights

- Descriptive statistics highlight differences across key evaluation criteria.
- Visualizations (boxplots, violin plots) illustrate comparative performance.
- Test report contains observations and conclusions about AI tool effectiveness.
